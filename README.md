# Wong

I have lost track of how many times I have written down something only to never find it again lost in the miriad of things that I have written. 

How many good thoughts have gone lost because of my inability to stay organized?

I know, I could probably download some very smart application that does this for me, but I figured that since I want to learn `rust` this is the perfect use case (or maybe it is only because I want it to be...).

Meet `Wong` the librarian that organizes my thoughts for me, because I am lazy and disorganized.

This aims to be an open source project, not even a good one for now, but I have some great ideas for its future.

For now, by running `cargo run TEXT CONTENT` the program should create a `.wong` directory down your `/home/{username}`, as well as a subdirectory with the year and one nested in that with the current month, which finally contains a plain text file named `{Day Of The Week} {# Day}`, with `[H-M]` headers for each note that you write to the file.

For now everything is contained in the `main.rs`, and I'll start building from there.

Good things will come, contributions not accepted yet but a nice chat is always welcome bye.
